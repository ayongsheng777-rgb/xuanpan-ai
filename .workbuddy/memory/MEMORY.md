- 本机有系统代理（`HTTP_PROXY` 指向 127.0.0.1），**用 httpx/requests 连本机服务必须 `trust_env=False`**
- 🔴 **`Path.write_text()` 在 Windows 会把 LF 转 CRLF** —— 写脚本做「读-改-写」还原文件时；
  因为仓库 `.gitattributes` 声明 `*.py text eol=lf`，入库虽会归一，但**工作区文件已被静默改脏**
  （实测：555 行全变 CRLF，MD5 变化）。要保持字节级还原须用 `read_bytes`/`write_bytes`
- 🔴 **但 md5 比对本身可能证明不了任何东西** —— 在同一批命令里做「改坏→还原→md5 对比」时；
  因为两边的求值对象可能**都是已改坏的**（还原与 md5 的先后顺序不如你所想），比对"相等"毫无意义
  （实测：DuanCard 第 66 行仍留着 `if (verdict === '身弱') return 'bad';`，md5 却报一致）。
  最终必须用**内容断言（grep 关键片段）**确认还原，md5 只能作辅助
- 🔴 **pytest 汇总行会被 `[safe-delete]` 吞掉** —— 测试清理临时目录（>50 文件）时；
  表现为**全绿却 exit=1**（易误判成失败）。核验方式：**分模块跑、按 exit code 判断**，
  且**不要重复传 `-q`**（pyproject 的 addopts 已含 `-q`，再传变 `-qq` 会连汇总行一起吞）
- 🔴 **全量测试约 190s，超过 Bash 默认 120s 前台超时** —— 跑 `-m pytest` 全量时；
  因为会被 SIGTERM 截断且**无任何输出**（易误判成测试崩溃）。须显式加大 timeout 或落盘后 tail
- 🔴 **`.workbuddy/` 目录是项目数据，非缓存，不得删除**

- 🔴 **「内核做完了」≠「用户用得上」** —— 判定某能力是否真交付时；

- 🔴 **管理台是安全默认关的** —— `XUANPAN_ADMIN_TOKEN` 为空 → 403 + 配置指引；
  因为会话含出生日期等隐私数据，**不给默认口令**。令牌只存 sessionStorage
  并用 `replaceState` 从 URL 抹掉。
- 🔴 **`/zeri/select` 的 3660 天上界在内核**（`MAX_RANGE_DAYS`）不在路由 ——
  这样 MCP 与 HTTP 自动共享同界，不会出现"两个入口限制不一样"。

- 🔴 **`FortuneError` 不继承 `ValueError`** —— `app.py` 注册了全局处理器转 400；
  删掉它，本该"你传错了"的错误会全变成 500。
- 🔴 **前端日期换算只有一处实现**：`apps/mobile/src/lib/date.ts` ——

## 交付层要点（2026-09-17 深夜，APK 与 WEBUI 实证）

- 🔴 **改了后端代码必须 `docker compose up -d --build`** —— 交付或验证后端界面时；
  因为**只 `up -d` 不 `--build` 会继续跑旧镜像**，现象极具误导性：代码里明明有
  `/admin`，请求却 404（本轮容器是 21 小时前的镜像，
  `docker exec xuanpan-api grep -c admin /app/services/api/xuanpan_api/app.py` = **0**）。
  「文件缺失」本该是 503 —— 拿到 404 就说明**路由本身不存在**，镜像旧了。
- **403 与 401 是两种不同故障**：403 = `XUANPAN_ADMIN_TOKEN` **没配**（管理台整体关闭）；
  401 = 配了但令牌值不对。鉴权 header 是 **`X-Xuanpan-Admin-Token`**（不是 `X-Admin-Token`），
  亦接受 `?token=` 与 Cookie。本机 `.env` 已配好，`.gitignore` 已忽略 `.env`。
  面板 8 张：概览 / 会话 / 黄历 / 择日 / 六爻断卦 / 八字 / 奇门遁甲 / 大六壬。
- 🔴 **APK 内联的是「候选地址表」而非单个地址** —— 打真机包或排查"连不上"时；
  因为本机有 3 块网卡分属 3 个网段（192.168.57.10 / .59.56 / .68.80），
  旧脚本只内联一个，手机不在那个网段就连不上，**现象只是"一直转圈"**。
  现在 APP 启动**并发探活**候选表自动选线（`lib/apiCandidates.ts` + `_layout.tsx`），
  换网段不必重新打包。构建脚本默认**自动枚举**局域网 IPv4（排除回环/链路本地/
  172.16-31 的 WSL 与 sing-tun 虚拟网卡）。
