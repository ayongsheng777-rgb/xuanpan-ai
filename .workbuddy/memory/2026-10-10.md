# 2026-10-10

## APP 装机回归修复：图标空白 + 「我的」页异常

阿勇装了 10-09 那版 APK（`xuanpan-ai-0.1.0-b1`），发来 7 张真机截图，三个问题。

### 一、所有图标显示为空白方块

**不是「字体没打进 APK」——字体一直在，是 RN 找不到它。**

准确根因（两个原因叠加）：

1. `app.json` 里 `"expo-font"` 是**空声明**（没有 `props.fonts`），
   其 plugin（`withFontsAndroid`）什么都不复制 → `assets/fonts/` 为空。
2. `@expo/vector-icons/build/Ionicons.js` 里 `createIconSet(glyphMap, 'ionicons', font)`
   把 family 注册为**小写** `ionicons`，而源字体文件名是 `Ionicons.ttf`（首字母大写）。
   RN Android 的 `ReactFontManager.createAssetTypeface` 用
   `Typeface.createFromAsset(assets, "fonts/<fontFamily>.ttf")` 拼路径 ——
   **文件名大小写不匹配 → 找不到**。

结果：`Font.isLoaded('ionicons')` 恒为 false → `componentDidMount` 走
`Font.loadAsync` → `expo-asset` 的 `downloadAsync` 在 standalone APK 里
拿到空 uri → 失败 → 组件 `render()` 返回 `<Text />` → **空白方块**。

> ⚠️ **复盘时差点误判**：我先用 `find . -name "Ionicons.ttf"` 在解包 APK 里查，
> 得 0 命中就写了「字体没进包」。**这是错的** —— APK 里一直有 19 个 `.ttf`
> 落在 `res/` 根目录（Metro asset registry 打的，文件名是 hash），
> 只是不在 `assets/fonts/`、且文件名不是 `ionicons.ttf`。
> 正确做法是**按 sha256 比对**（`res/CU.ttf` 就是 Ionicons.ttf）。

**修复**：
1. `app.json` 给 `expo-font` 显式列字体路径（让它复制到 `assets/fonts/`）。
2. 写自定义 plugin `apps/mobile/plugins/withAndroidFonts.js`（约 40 行）：
   接受 `{ src, family }`，把 src 复制为 `assets/fonts/<family>.ttf`（小写）。
   - ⚠️ **不能用 `createRunOncePlugin` 包装** —— `withStaticPlugin` 在加载 module
     时就会 `assertInternalProjectRoot`，报
     `Config _internal.projectRoot isn't defined by expo-cli`。
     直接 `module.exports = function(config, props){...}` 即可。

### 二、「我的」页面只剩一张「配置模型」卡

**不是 bug，是默认分段选错了。**
mine 页用 `SegmentedTabs` 把 6 张卡分成「模型 / 我的 / 关于」三段，
默认 `section='model'` —— 但底栏文案是「我的」，
用户进「我的」只看得到一张 AI 模型卡，找不到「我的信息」「网络线路」。

**修复**：默认分段改为 `mine`。现在进页直接显示
「我的信息」+「网络线路」两张卡。

（字体空白放大了这个问题：分段标签的文字渲染不出来，
用户根本看不出上面还有个可切换的三段控件。）

### 三、一屏显示

复核后**移动端 17 页全部合格**（`h=844 inner=0 clip=0 ox=0`）。
用户感知的"不完整"来自上面两个问题的叠加 ——
「我的」页只有一张卡 + 大片空白，看起来像内容没加载完。

### 验证

- `expo prebuild` 本地：`android/app/src/main/assets/fonts/ionicons.ttf` 存在，sha256 与源一致
- EAS 构建 `2dec37fa-8ebe-4970-8d5b-9390680ae094`（b3）解包：
  `assets/fonts/ionicons.ttf` 存在，sha256 `9c7fb907…916b` 与源一致
- 运行时链路（源码级推导）：native `queryCustomNativeFonts()` 扫描 `assets/fonts/`
  → 返回 `['ionicons']` → `Font.isLoaded('ionicons')` = true → **跳过失败的 loadAsync**
  → RN 用 `fonts/ionicons.ttf` 加载成功
- `tests/mobile`：410 passed / 1 skipped
- 全页真实渲染：17 页全 `h=844 inner=0 clip=0 ox=0`
